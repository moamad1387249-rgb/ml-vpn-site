راهنمای انتشار سایت ML.VPN با گوشی
محتویات ZIP:
- index.html: محتوای سایت
- style.css: طراحی فضایی مشکی، آبی نئونی و طلایی

انتشار رایگان با GitHub Pages:
1) با مرورگر گوشی وارد https://github.com شوید و وارد حساب شوید یا حساب بسازید.
2) یک repository جدید بسازید؛ نام پیشنهادی: ml-vpn-site
3) گزینه Add file > Upload files را بزنید و index.html و style.css را بارگذاری و commit کنید.
4) از Settings > Pages، انتشار از شاخه main و پوشه /(root) را فعال و Save کنید.
5) پس از انتشار، آدرس معمولاً شبیه https://USERNAME.github.io/ml-vpn-site/ است؛ USERNAME نام کاربری واقعی شماست.
